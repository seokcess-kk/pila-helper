# 08. 핵심 화면 와이어프레임 (MVP)

> 기준: 재조정된 **MVP 범위**([04 §2](04-roadmap-mvp.md)) · 단일 반응형 웹앱(PWA)+역할기반 뷰([05 C-7]) ·
> 스튜디오 게이트([05 D-2]) · 현금주의 손익([06 §6.4]) · SMS 손익캡처([05 D-5]).
> ASCII 목업은 레이아웃 의도 전달용(픽셀 아님). 각 화면에 **데이터 매핑 + 규칙 + 엣지케이스** 주석.

---

## 0. 설계 원칙

- **하나의 앱, 역할별 뷰**: 같은 코드, 로그인 역할(`owner`/`member`)에 따라 다른 내비·홈.
- **운영자 = 데스크톱 우선**(타임테이블·손익은 넓은 화면), **회원 = 모바일 우선**(PWA).
- **차별화는 첫 화면에**: 운영자 대시보드와 손익에서 *"이번 달 얼마 남았는지"*를 즉시.
- **MVP 절제**: 매니저/강사 세부권한·셀프가입 승인큐·자유수강형 자동폐강·캠페인은 화면에 자리만 표시하고 `(v1)` 라벨.

## 1. 화면 인벤토리 (MVP 우선순위)

| # | 화면 | 역할 | 우선 | 핵심 가치 |
|---|------|------|------|-----------|
| S1 | 운영자 대시보드 | owner | ★★★ | 오늘 운영 + **이번달 순이익** 한눈 |
| S2 | 주간 타임테이블 | owner | ★★★ | 예약/스케줄 운영 중심 |
| S3 | 수업 상세 · 출결 | owner | ★★★ | 출석→차감, 폐강→복구 |
| S4 | 회원 목록 | owner | ★★ | 검색·필터 |
| S5 | 회원 360° 상세 | owner | ★★★ | 수강권/홀딩/미수금/이력 |
| S6 | 수강권 발급 (모달) | owner | ★★ | 판매·결제·현금영수증 |
| S7 | **손익** | owner | ★★★ | ★차별화: SMS큐+현금주의 순이익 |
| S8 | 회원 예약 (모바일) | member | ★★★ | 셀프 예약 |
| S9 | 마이페이지 (모바일) | member | ★★ | 내 수강권/예약 |
| S10 | 가입·온보딩 흐름 | member | ★★ | 초대→인증→동의 |
| S11 | 매장 셋업 마법사 | owner | ★★ | 5분 온보딩 |

> **구역(D-6)**: S1~S6 = 운영 콘솔 / **S7 손익 = 재무 어드민(owner 전용 🔒)** + 비용·매출분석·미수금·정산 / S11 = 설정 / S8~S10 = 회원앱.

## 2. 내비게이션 IA — 운영/재무 구역 분리 (D-6)

> 같은 앱·같은 데이터. **재무는 owner 전용 별도 구역**, 운영 대시보드에 **손익 브리지**로 연결.
> 판매 '행위'=운영(회원360°에서 발급) / 매출 '분석'=재무. `sale` 데이터는 하나, 보는 면만 다름.

```
운영자 (데스크톱 좌측 사이드바)                     회원 (모바일 하단 탭)

◆ 운영 콘솔 (CRM+예약) · owner + staff(v1)           ┌───────────────────────┐
  🏠 운영 대시보드 ──[이번달 순이익 +318만 →]┐       │ 📅예약  🎫수강권  👤MY │
  📅 타임테이블                              │       └───────────────────────┘
  👥 회원                                    │브리지  (+ 🔔 상단 벨)
  🎫 수강권 발급·판매                        │
  ✅ 출결    ✉️ 메시지                       │
                                            ▼
◆ 재무 / 경영 🔒 owner 전용 ◀────────────────┘
  💰 손익(현금주의)   📥 거래 확인 큐(SMS/CSV)
  🧾 비용   📈 매출 분석   💳 미수금   👤 강사정산(v1)

◆ ⚙️ 설정 — 매장·수업·수강권상품·강사·정책
```

## 3. 운영자 화면 (데스크톱)

### S1. 대시보드 🏠

```
┌─ 필라헬퍼 ───────────────────────────────  [모던필라테스 ▾]  [🔔 3]  [원장님 ▾] ┐
├──────────┬───────────────────────────────────────────────────────────────────────┤
│🏠 대시보드│  목요일 2026-06-12                                                      │
│📅 타임테이블│ ┌─ 오늘 수업 ───────────┐  ┌─ 이번 달 순이익 (현금주의) ★ ───────────┐│
│👥 회원    │ │ 예약 12 · 대기 2       │  │      + 3,180,000원                       ││
│🎫 매출    │ │ 노쇼 1 · 빈자리 3      │  │   ▲ 지난달보다 42만원 더 남았어요        ││
```

- **데이터**: 순이익=현금주의(transaction: SMS+CSV+수기, §6.4) / 매출·미수금=`sale`−`payment.is_received` / 만료임박=`member_pass.expire_at` / 오늘일정=`class_session`+`booking`.
- **규칙**: 순이익엔 약정매출(`sale`) 미합산 → "수입 5.60M"은 **실입금** 기준.
- **MVP 라벨**: "재등록 안내"는 `(v1 캠페인)` — MVP는 만료 자동 알림까지.

- **인사이트**: "지난달보다 +42만", "공과금 ▲40%"(이상감지) — 한 줄 카피.

## 7. 반응형 · 상태 · 엣지케이스 노트

- **반응형**: 운영자 타임테이블/손익 = 데스크톱 그리드 / 모바일은 일간·요약. 회원 화면 = 모바일 우선.
- **빈 상태**: 회원 0명 → "첫 회원을 초대하세요" CTA / 거래 0건 → "문자 알림을 켜면 자동으로 채워져요".
- **에러/거부**: 예약 실패 시 사유 코드 노출(§6.1). 미승인 회원 게이트 안내.
- **로딩/동시성**: 마지막 1석 예약 충돌 → "방금 마감되었어요" + 대기 전환(§6.5).
- **권한(MVP)**: owner 단일 풀권한. manager/instructor 뷰는 자리만, 세부 스코프 `(v1)`.
