# 09. MVP 백로그 · 스프린트 분할

> 기준: 재조정 MVP([04 §2]) · 운영/재무 구역 분리([05 D-6]) · 핵심 규칙([06 §6]) · 와이어프레임([08]).
> 목적: "기능을 빠르게 다 구현 → 하나하나 다잡기"를 **표류 없이 트랙별로 굴러가게** 하는 실행 계획.

## 0. 전제 · 방법

- **트랙**: `[운영]`(CRM+예약) · `[재무]`(owner 전용 🔒) · `[회원앱]` · `[공통]`(기반/인프라). → D-6 구역과 일치.
- **전략**: **얇은 수직 슬라이스 우선**(스프린트마다 데모 가능한 산출물) → 폭(breadth)을 빠르게 채운 뒤 **다잡기(하드닝)**.
- **추정(T-shirt)**: `S`≤2일 · `M`3–5일 · `L`1–2주 · `XL`(분할 필요).
- **가정**: 개발 1~2명, 2주 스프린트. **2명이면 Sprint 2부터 운영/재무 병렬**(§5).
- **공통 횡단**: 한국어 UI · 반응형(운영=데스크톱 그리드/모바일 요약, 회원=모바일) · PWA · 스튜디오 게이트 · 멀티테넌시(studio_id).

## 4. 스프린트 계획 (1~2명·2주 기준)

| 스프린트 | 목표(데모 가능 산출물) | 포함 티켓 |
|----------|------------------------|-----------|
| **S0 — 골격** | 로그인하고 매장·룸·강사·수업유형·수강권상품을 만든다 | FND-1~5, SET-1~4 |
| **S1 — 회원+판매** | 회원 초대 등록 → 10회권 발급 → 미수금까지 | MBR-1~5, PAS-1·2·3·6, SET-5·6, NOT-1 |
| **S2 — 예약 심장** | 주간 타임테이블·셀프예약 자격검증·출결 차감·폐강 복구 | FND-6, BKG-1~6, MBR-4 |
| **S3 — 회원앱+알림** | 회원이 폰으로 예약·취소, 만료/예약 알림 자동 | APP-1~5, NOT-2~4, BKG-7 |
| **S4 — 재무(차별화)** | "이번 달 순이익(현금주의)"이 보인다 | FIN-1·2·3·5·7, DSH-1·2 |
| **S5 — wedge+다잡기** | 문자만 켜두면 순이익 자동 + 하드닝 | FIN-4(SMS)·6·8, PAS-4·5, DSH-3, NFR-1~4 |

- **S0~S3 = "예약·회원은 경쟁사만큼"** (운영 본질) → **S4~S5 = "돈 관리는 경쟁사가 못 하는"** (차별화).
- 각 스프린트 끝에 **파일럿 매장에 데모** 가능 → 피드백으로 "다잡기".

## 5. 두 트랙 병렬화 가이드

- **1명**: 위 순서대로 직렬(S0→S5). 차별화는 S4부터.
- **2명(권장)**: `PAS-2`(S1) 완료 후 분기 —
  - **개발 A(운영)**: BKG → APP → DSH (S2~S3)
  - **개발 B(재무)**: FIN-2→3→5→7 (S2부터 병렬, SMS PoC 포함)
  - → 재무가 앞당겨져 **약 4스프린트로 압축**, 차별화를 더 일찍 검증.
- **선행 스파이크**: `FIN-4 SMS 캡처`는 스프린트 진입 전 **안드로이드 PoC**(권한·파싱 신뢰도)로 타당성 확정.

## 6. Definition of Done (티켓 유형별)

- **모델/API**: 마이그레이션 + studio_id 스코프 + 단위테스트 + 권한 체크.
- **화면**: 반응형(데스크톱/모바일) + 빈/에러/로딩 상태 + 한국어 카피.
- **규칙(§6)**: 규칙표대로 통과/실패 케이스 테스트(예: 예약 자격 6케이스).
- **재무**: **현금주의 정합**(이중계상 없음) 검증 + owner 게이트 확인.
- **공통**: 접근 로그(민감), 기본 분석 이벤트.

## 7. "하나하나 다잡기" — 하드닝 백로그 (폭 채운 뒤)

브레스 완성 후 깊이 보강할 테마(스프린트 사이/후):
- **예약 엣지**: 당일취소·노쇼 패널티 정밀화, 동시성 스트레스, 휴강 일괄처리.
- **수강권 엣지**: 부분환불 계산·양도(→ v1), 홀딩 만료연장 경계, 다수 수강권 충돌.
- **재무 정확도**: 카드사 합산정산 추정 대사 정교화, 분류 규칙 자동학습(→ v1), 영수증 OCR(iOS 보완).
- **알림 도달**: 알림톡 채널·템플릿 심사 도입, iOS 푸시 설치 전환.
