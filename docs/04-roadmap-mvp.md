# 04. MVP 범위 · 로드맵 · 차별화 전략

---

## 1. 제품 전략 한 장 요약

| 구분 | 내용 |
|------|------|
| 타겟 | 1~3룸 소형 필라테스 스튜디오 (오너=강사 또는 소수 강사) |
| 핵심 가치 | ① 예약/회원 행정 자동화로 **시간 절약** ② **순이익을 보여줘서** 운영 의사결정 |
| 진입 자격 기능 | 예약·회원·수강권·판매매출 (경쟁사 수준) |
| 이기는 기능 | **현금흐름 기반 자동 손익 + 재등록 CRM + 강사 자동정산** |
| 도입 장벽 | 하드웨어 無, 5분 온보딩, 무료 체험 |

## 2. MVP 정의 (1차 출시 = "운영 본질 + 차별화의 씨앗")

> 목표: **"예약·회원은 경쟁사만큼, 돈 관리는 경쟁사가 못 하는 첫 버전"**

### 포함 (Must) — 리뷰 반영 재조정
1. **회원 관리**: **운영자 초대 등록**·검색·360°(수강권·이력)·엑셀 일괄등록. 가입 시 **약관/개인정보 동의 필수**. (셀프가입+승인큐는 v1)
2. **예약/스케줄**: 타임테이블, 예약·대기·취소·폐강, **회원 셀프 예약**, 출석·자동차감, **예약 자격검증·차감시점 정책**(06 §6). 자유수강형 자동폐강은 v1.
3. **수강권/결제**: 상품정의, 발급, 잔여·만료, **홀딩(정지/재개)·단순환불·미수금**, 결제수단·**현금영수증** 기록(수기 OK)
4. **수업/강사**: 강사·근무시간, 수업유형(개인/듀엣/그룹)/정원
5. **알림**: 예약 확인/취소, **수강권 만료·잔여 알림** (채널은 문자/푸시 우선, 알림톡은 심사 후)
6. **★ 매출·손익(현금주의)**: 판매매출 집계 + 비용 수기입력 + **카드/입금 문자(SMS) 자동캡처** + CSV 업로드 + **월 순이익 요약**. (규칙 자동학습은 v1)
7. **대시보드**: 오늘 예약/노쇼, 이번달 매출, **★이번달 순이익(현금주의)**, 만료임박 회원
8. **권한**: 오너 중심 (매니저롤·강사 담당회원 스코프는 v1)
9. **모바일**: 단일 반응형 웹앱(PWA)+역할 뷰. **기본 데이터 내보내기(CSV)** 포함

### 제외 (Later)
- 마이데이터/오픈뱅킹 **자동** 연동 (→ v1, 법무 후) — MVP는 **SMS캡처+업로드**로 대체
- 거래 **자동분류 규칙엔진·학습**, 손익 마감 캐시 (→ v1)
- 회원 **셀프가입+승인큐+병합**, 매니저롤·강사 담당회원 스코프 (→ v1)
- 자유수강형 **자동폐강 잡** (→ v1)
- 얼굴인식·키오스크·출입통제 하드웨어
- 다지점, PG 결제, 전자계약 전자서명, 세무 신고연동

### MVP 성공 기준(가설)
- 온보딩→첫 예약 오픈까지 **10분 이내**
- 사장님이 **주 1회 이상 손익 화면** 확인
- 만료알림으로 **재등록 전환** 발생 (리텐션 지표)

## 3. 단계별 로드맵

### Phase 0 — MVP (운영 + 손익 wedge)
위 MVP 범위. **차별화 메시지**: "예약도 되고, **이번 달 얼마 남았는지도 자동으로** 보여요(문자 캡처 기반 현금주의 순이익)."

### Phase 1 — v1 (자동화·차별화 본격)
- ★ 통장/카드 **마이데이터/오픈뱅킹 자동 연동**(제휴) + 자동 대사 + **거래 자동분류 학습**
- ★ 강사 급여 **자동 정산** → 손익 자동 반영
- ★ 재등록·이탈방지 **타겟 캠페인**(만료임박/출석급감 세그먼트)
- 회원 **셀프가입·승인큐**, 매니저롤·강사 담당회원 스코프, **자유수강형 자동폐강**
- 회원 건강·운동 기록(세션노트), 손익 추이/구성 리포트·목표대비
- 대기자 자동승급, 반복수업, **부분환불 계산·양도**(단순환불·홀딩은 MVP)

### Phase 2 — v2+ (확장·수익화 심화)
- 세무 내보내기 / 예상세금 / 손익분기 관리
- PG 인앱결제, 전자계약 전자서명
- 다지점 통합, 키오스크/QR(선택), 강사 마켓/대체강사
- 이상감지·예측 인사이트, 리뷰/추천 리텐션

## 4. 차별화 포인트 (경쟁사 대비 "왜 우리?")

| # | 차별화 | 경쟁사 현황 | 우리 |
|---|--------|------------|------|
| 1 | **현금흐름 손익** | 판매매출만(약정) | 통장·카드 엮어 **순이익** |
| 2 | **강사 자동정산→손익 편입** | 정산 일부 제공 | 정산값이 **비용으로 자동** |
| 3 | **재등록·이탈 CRM** | 만료 알림 수준 | 세그먼트+캠페인 **자동** |
| 4 | **건강/운동 기록** | 약함 | 강습형 특화 세션노트 |
| 5 | **사장님 1화면 대시보드** | 매출 위주 | 예약·매출·**순익**·재등록 통합 |
| 6 | **소형 친화 도입** | 하드웨어·범용 복잡 | 무하드웨어·5분·무료체험 |

> 핵심 포지셔닝 문장:
> **"예약 잡아주는 건 다 하죠. 필라헬퍼는 '이번 달 얼마 남았는지'까지 알려줍니다."**

## 5. 리스크 & 대응

| 리스크 | 영향 | 대응 |
|--------|------|------|
| 금융 자동연동 규제(마이데이터 허가) | 차별화 핵심 지연 | **MVP는 SMS캡처+업로드로 "자동 손익" 체감 제공**(라이선스 불요), v1은 제휴로 승급, 법무 선검토 |
| **손익 회계기준 혼란**(이중계상) | 순이익 숫자 신뢰 붕괴=차별화 자폭 | **현금주의 단일 기준** 고정, sale은 영업지표만 (06 §6.4) |
| 알림톡 심사·iOS PWA 푸시 한계 | 리마인더 도달률 | MVP는 **문자/푸시 우선**, 알림톡은 채널·템플릿 심사 후. iOS는 설치 유도 |
| 보안·컴플라이언스(금융·민감정보) | 유출 시 치명 | 암호화·접근통제·동의·처리방침, 자동연동 전 보안 점검 |
| 예약·회원 기능 레드오션 | 차별화 부족 시 묻힘 | 손익+CRM으로 묶음 가치, 단품 경쟁 회피 |
| 무료(어시스트핏) 경쟁 | 가격 압박 | 예약은 무료/저가, **손익·정산은 유료 플랜**(가치과금) |
| 카카오 알림톡/PG 비용 | 운영원가 | 종량 패스스루 or 플랜 포함 한도 |
| 소상공인 데이터 입력 피로 | 손익 정확도 | 자동분류·반복템플릿·확인큐로 입력 최소화 |
| 개인정보(건강기록) | 보안/법 | 암호화·동의·접근권한 설계 |

## 6. 수익 모델 가설 (초안)

- **Free/Lite**: 예약·회원·기본 알림 (어시스트핏 대항, 진입)
- **Pro(유료, 월 구독)**: **손익 리포팅 + 자동연동 + 강사정산 + 재등록 CRM** (가치 과금 지점)
- **Add-on 종량**: 알림톡 발송량, PG 수수료, 추가 지점
- 가격 결정 전제: 경쟁사 1~12개월 구독 / 어시스트핏 무료 → **"예약은 저렴, 돈관리는 유료"** 구조 권장
