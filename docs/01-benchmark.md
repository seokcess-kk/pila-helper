## 1. 스튜디오메이트 (StudioMate) — 1순위 벤치마크

출처: https://studiomate.kr/ , App Store / Google Play(회원용·관리자용)

### 제공 기능 (카테고리별)

**회원관리**
- 조건별 회원 목록 조회
- 회원별 구매한 수강권 결제 내역 + 이용 내역 확인
- 회원 데이터 체계적 관리

**예약/스케줄 관리**
- 실시간 수업 스케줄: 예약 / 예약대기 / 취소 / 폐강 상태 실시간 반영
- 수강권 종료일·잔여 횟수 자동 공지
- 당일 예약 변경 가능
- 회원앱·관리자앱으로 언제 어디서나 예약/취소 → **전화 응대 부담 제거**

**수강권 관리**
- 개인/그룹 수업별 수강권 타입 설정
- 수강 타입 설정으로 판매·관리

**수업 관리**
- 수업 등록부터 수업별 수강 회원 목록 조회
- 그룹/프라이빗 수업 관리
- 강사별 근무시간 설정

**매출/정산**
- 매출 페이지: 수강권·수업 등 전체 매출 + 포인트 내역 한눈에
- 리포트 기반 관리
- 미수금 자동 입력

**운영 설정**
- 시설 영업시간 + 강사별 근무시간(요일/시간별)
- 공휴일/휴일 특별 일정
- 역할별 접근 권한(오너/매니저/강사)
- 예약·취소 운영정책 설정
- 게시판 / 락커 / 체크인

**모바일 앱**
- 회원용 앱(iOS/Android), 관리자용 앱(iOS/Android)

**가격**: 1년 약정 비강요, 합리적 가격대 표방 (구체 금액 비공개)

### 강점
- 강습형(필라테스/요가/PT)에 특화된 깔끔한 UX, 회원 셀프 예약 완성도
- 수강권 만료/잔여 자동 공지 → 재등록 유도에 유리

### 약점/빈틈 (우리가 보완할 포인트)
- 매출은 **'판매 기준'**(수강권 결제)일 뿐, **실제 통장 입금/카드 비용**과 연결 X
- 비용(임대료/강사급여/물품/공과금) 관리 기능 약함 → **손익(순이익)** 을 못 봄
- 세무/정산 도우미 부재

## 2. 브로제이 (BroJ) CRM

출처: https://crm.broj.co.kr/ , https://company.broj.co.kr/ (업계 1위 표방)

### 제공 기능
**출입/인식**
- 얼굴인식 출입 (99.6% 인식률, 0.5초 출석)
- 실시간 회원 데이터 연동 출입제어
- 무인결제 키오스크

**회원/수업 관리**
- 클라우드 CRM + 모바일 앱
- 수업예약: 예약알림 / 노쇼(No-show) 관리 / 급여정산 / 자동폐강
- 태블릿 전자계약서

**서비스 범위**: 헬스장·PT·태닝·체육관·필라테스·요가·골프·테니스

**가격**: 1 / 3 / 6 / 12개월 단위 구독

### 강점
- 하드웨어(얼굴인식·키오스크·출입통제)까지 묶는 **통합 운영**
- 노쇼 관리, 자동폐강, 강사 급여정산 등 운영 자동화 성숙

### 약점/빈틈
- 전업종 범용 → 소형 필라테스에는 **과한 기능/비용**일 수 있음
- 하드웨어 의존 → 1~2룸 소형 샵은 도입 부담
- 역시 **현금흐름 기반 손익 리포팅**은 범위 밖

## 3. 아하루 (aharu) — ★ 가장 근접한 직접 경쟁자 (정밀 분석)

출처: https://help.aharu.kr/ (도움말 40개 페이지 전수 분석, 2026-06-11)
슬로건: **"필라테스 센터 운영을 더 쉽게"** — **필라테스 전용 올인원 솔루션**.

### 서비스 구조 (3개 클라이언트)
| 대상 | 형태 | 핵심 |
|------|------|------|
| 🧘 수강생 | 모바일 앱(iOS/Android) | 예약·일정·**운동일지/자세**·수강권·커뮤니티 |
| 👩‍🏫 강사/관리자 | 모바일 앱(iOS/Android) | **여러 센터 출강+개인수업 통합 일정**·회원·정산·통계 |
| 🏢 센터 운영자 | **PC 웹**(브라우저 최적화) | 센터 운영 전반(아래) |

### 운영자 웹 기능 (전체)
- **일정 관리**: 월/주/일 캘린더, 개인수업 / 그룹수업(자유수강형·정규수업형) / 상담 / 휴일(정기·임시). 색상 구분(개인·센터·그룹·상담·휴무)
- **수업 관리**: 수업목록·예약내역·취소수업, 출결처리(출석/결석/지각/노쇼)
- **회원 관리**: 직접등록 / 앱 등록요청 승인 / **엑셀 일괄등록** / **타 프로그램 데이터 이전**. 회원 상세=수강권·예약·출석·결제이력. 검색(이름·연락처) + 필터(수강권상태·등록일·활성/휴면)
- **수강권 관리**: 템플릿 발급, **정지/재개 시 유효기간 자동연장**, 만료 예정 안내
- **상품 관리**: 판매상품(운동복·양말) + **대여상품(그립삭스·소도구) 반납처리**
- **멤버(강사/스태프)**: 역할 4종(대표/매니저/강사/스태프) + 권한 매트릭스(회원·수강권·정산·설정)
- **정산 관리**: 매출(총/수업/상품) · **지출 등록(영수증 첨부)** · **미수금** · **포인트** · 강사정산(건당/월고정/비율) · 엑셀 다운로드
- **메시지**: 단문/장문 문자 · **카카오 알림톡** · 자동발송(예약확정·리마인더·취소·수강권만료·생일축하)
- **공지사항/Q&A**: 센터 공지 + 회원 묻고답하기
- **출석 관리**: **"🚧 개발 예정"**(QR출석·출석률 통계·노쇼 패널티) — 현재는 수업/일정에서 수기 출결
- **설정**: 센터정보(사업자번호 선택), 영업시간(점심시간), 예약규칙(오픈 N일전·마감 N시간전·취소마감·1일 예약제한), 취소/환불(전액복구·차감유지·일부차감), 노쇼 패널티

### 수업 형태 3종 (디테일이 좋음 — 우리 데이터모델에 참고)
| 형태 | 예약 방식 | 진행 조건 | 취소 |
|------|----------|----------|------|
| 개인수업 | 회원이 시간 선택 | 항상 | 앱 취소 |
| 그룹-정규수업 | **관리자가 인원 배정** | 항상 | 센터 문의 |
| 그룹-자유수강형 | **회원 직접 예약** | **최소인원 충족 시** | 앱 취소 |
> 자유수강형은 **최소인원 미달 시 자동 폐강 + 수강권 자동 복구** + 앱 알림.

### 강점 (아하루가 잘하는 것 = 소형 필라 표준의 끝판)
1. **필라테스 전용 UX** — 요가/PT 군더더기 없이 필라에 최적화
2. **멀티센터/프리랜서 강사 통합 일정** — 출강 많은 강사 시장을 정조준 (앱의 "핵심 기능")
3. **운동일지 + 자세 라이브러리** — 회원이 센터 없이도 개인 운동 다이어리로 사용. 자세 DB(기구/매트/소도구/부위별, 이미지·타겟근육·주의사항), 수업 연동 시 자동입력
4. **커뮤니티** — 전문가(강사 네트워킹·구인구직) + 센터 회원(공지·Q&A·1:1채팅)
5. **프리랜서 강사·1인 스튜디오 무료** — 진입장벽 제거(어시스트핏식 전략)

### 약점/빈틈 (우리가 이기는 지점)
- **지출이 수기 입력 + 영수증 첨부일 뿐** → **통장/카드 자동연동 없음**, 따라서 **순손익(수입−비용) 자동 리포팅 부재** (매출·지출을 한 화면에 보여줄 뿐, "실제 통장에 남은 돈"은 모름) ← **우리 핵심 차별화 유효**
- 출석관리(QR/통계/노쇼 패널티 자동화) **아직 개발 예정** ← 우리도 후순위라 동률
- 재등록/이탈 **예측·자동 타겟 캠페인**은 없음(만료 알림 수준) ← 우리 CRM 차별화 여지
- 운영자 기능이 **PC 웹 전용** → 사장님이 폰으로 손익 보기 어려움 ← 우리 "모바일 손익 대시보드" 기회

## 5. 종합: "이미 표준이 된 기능" vs "비어 있는 기능"

### A. 표준 기능 (반드시 구현 = 진입 자격)
1. 회원 관리(프로필/구매·이용 이력)
2. 실시간 예약/대기/취소/폐강 + 회원 셀프예약(앱)
3. 수강권(개인/그룹, 회차/기간, 잔여·만료 관리·자동 차감)
4. 수업/강사 스케줄, 강사별 근무시간
5. 판매 매출 리포트 + 미수금
6. 알림(예약 확인/취소, 수강권 만료, 노쇼)
7. 역할별 권한(오너/매니저/강사)
8. 회원용·관리자용 모바일 접근

### B. 차별화 기능 (보완·추가 = 우리가 이기는 지점)
1. **★ 통장/카드 연동 자동 손익 리포팅** (수입-비용=순이익, 마이데이터/오픈뱅킹) → [03 문서](03-finance-reporting.md)
   — 아하루조차 지출은 수기일 뿐, 이 기능은 **전 경쟁사 통틀어 빈칸**
2. **강사 급여 자동 정산**(수업 실적 × 정산룰) + 비용으로 손익에 자동 반영
   — 아하루는 정산값 계산까지만, 우리는 **그 값을 손익의 '비용'으로 자동 편입**
3. **재등록/이탈 예측 CRM**(만료 임박·출석 급감 회원 자동 타겟팅 + 메시지)
   — 경쟁사는 만료 '알림'까지, 우리는 '세그먼트+캠페인'
4. **사장님용 '오늘/이번달' 대시보드 — 모바일에서**(예약·매출·**순익**·재등록 한 화면)
   — 아하루 운영자기능은 **PC 웹 전용** → 폰에서 순익 보는 경험으로 차별화
5. **소형 친화 가격/온보딩**(하드웨어 無, 5분 셋업, 무료 체험)

### C. 아하루에서 배운 것 (우리가 흡수하면 좋은 표준 — 기획 보강 후보)
> 아하루는 소형 필라 표준의 완성형. 아래는 우리 기획에 반영을 검토할 항목.

1. **수업 형태 3종**(개인 / 그룹-정규 / 그룹-자유수강형) + 자유수강형 **최소인원 미달 자동폐강·수강권 자동복구** → 데이터모델 `class_session`에 `min_capacity`, `class_format` 반영 검토
2. **운동일지 + 자세 라이브러리**(회원 셀프 + 수업연동 자동입력) → 우리 `session_note`/`health_record`를 회원앱 셀프기록 + 필라 자세 DB로 확장 검토
   — ⚠️ 단, **아하루식 '센터 없이 단독 사용'은 미채택**. 우리는 **스튜디오 게이트**(스튜디오메이트형, 등록 회원만) → [05 D-2](05-open-questions.md)·[07 §1](07-member-management.md)
3. **상품 대여/반납**(그립삭스·소도구) → `sale` 외 `rental` 개념 추가 검토
4. **회원 포인트 제도** → 리텐션 수단으로 검토
5. **엑셀 일괄등록 + 타 솔루션 데이터 이전** → 전환(마이그레이션) 온보딩은 **도입 필수** (이게 약하면 갈아타질 못함)
6. **커뮤니티(전문가+센터)** → 강습형 리텐션 요소. 단, 범위 크므로 우선순위 낮게.
7. **클라이언트 분리 전략 재고**: 아하루=운영자 PC웹 + 강사/회원 앱. 우리는 "반응형 웹 우선"이나, **강사·회원은 결국 앱 니즈** → 단계 전략 점검 → [05 문서](05-open-questions.md)

## 6. 수업·예약 형태 비교 (데이터모델링용 조사)

> 조사일 2026-06-11. 출처: 각사 공식/도움말 + 필라테스 강사 가이드(gongysd) + 검색.
> 참고로 발견한 추가 솔루션: 하이파이브(무료 예약·재등록 알림), 다짐매니저(출석·자동차감), 필라노트(수업기록 전용), 클래스웍스(예약), 위링크.

### 솔루션별 수업/예약 형태
| 솔루션 | 수업 규모 유형 | 예약 방식 | 진행 조건 | 특이점 |
|--------|--------------|----------|----------|--------|
| 스튜디오메이트 | 개인 / 듀엣 / 그룹(프라이빗·그룹) | 회원 셀프 + 예약대기 | 항상 | 수강타입별 수강권 |
| **아하루** | 개인 / 그룹-정규 / 그룹-**자유수강형** | 자유수강=셀프 / 정규=관리자 배정 | 자유수강=**최소인원** | 미달 자동폐강+수강권 복구 |
| 위링크 | 개인 / 듀엣 / 그룹 | 예약제 | 항상 | 통합 운영 |
| 클래스웍스 | 개인 / 그룹 | 회원 예약 | 항상 | 횟수제/기간제 이용권 |
| 어시스트핏 | 1:1 / 그룹 클래스 | 1:1 예약 + **그룹 자리(좌석) 예약** | 항상 | QR 체크인 |

### 한국 필라테스 수업 형태의 "표준 축" (모델 설계 기준)
1. **인원 규모/비율**: 개인(1:1 프라이빗) · 듀엣(2:1) · 트리오(3:1) · 소그룹(4~8)
2. **사용 도구(필라 특화)**: 기구(리포머·캐딜락·체어·바렐) · 매트 · 소도구(폼롤러·밴드·볼)
3. **예약 주체**: 회원 셀프(드롭인/자유수강) ↔ 관리자 배정(정규·**고정반**=매주 같은 시간 자동)
4. **진행 조건**: 항상 진행 ↔ **최소 인원 충족 시**(미달 자동폐강)
5. **좌석/기구 지정**: 옵션 — 리포머 머신 번호·그룹 자리 지정(어시스트핏 등 일부)
6. **회차 차감**: 수업·수강권 유형별 차감 규칙(개인권↔그룹권 분리)

> 시사점: 경쟁사 대부분 **개인/듀엣/그룹 + 회원 셀프예약**이 공통.
> 아하루의 **자유수강형(최소인원 자동폐강)**과 어시스트핏의 **좌석 지정**이 차별 디테일.
> 우리 모델은 이 6축 중 **어디까지 1차 지원할지**를 정해야 함 → [05 문서](05-open-questions.md) 재질문.
